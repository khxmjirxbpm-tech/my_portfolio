## ฟีเจอร์ในเว็บ
- คลิกที่รูปเพื่อขยายเต็มจอ พร้อมซูมเข้า/ออก ลากเลื่อนดู ดับเบิลคลิก/แตะซูมเร็ว
- เมนูเต็มจอ (ไอคอน ☰) แสดงหัวข้อทั้ง 12 หน้า พร้อมแอนิเมชันไล่จังหวะ
- ปุ่มก่อนหน้า/ถัดไป + ปัดซ้ายขวาบนมือถือ + ลูกศร ← → บนคีย์บอร์ด
- ทรานซิชันเปลี่ยนหน้าแบบ fade เนียนๆ (เบราว์เซอร์ที่รองรับ)
- แสงสีชมพูจางๆ ตามเคอร์เซอร์บนหน้าปก/ปกหลัง
- ข้อความ/รูป blur เข้าโฟกัสตอนโหลดหน้า
